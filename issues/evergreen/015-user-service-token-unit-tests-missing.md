# Issue: UserService Token Composition Unit Tests Are Missing

## Severity

Medium

## Description

There are no focused unit tests validating JWT claim composition and token metadata generated by `UserService`.

Security-sensitive token behavior can regress silently without dedicated coverage.

## Proposed Updates

1. Add unit tests for token claim composition in `UserService`.
2. Verify required claims are present and correctly populated.
3. Verify issuer/audience values and expiration behavior are correct.
4. Include failure-path tests where required configuration is missing.

## Verification Steps

1. Create `UserService` token tests.
2. Run `dotnet test`.
3. Confirm tests fail when claim composition is intentionally broken.
4. Confirm tests pass with expected token behavior.
